# Hostel Management System — Slidev

Getting started:

- `pnpm install`
- `pnpm dev`
- visit <http://localhost:3030>

Edit the [slides.md](./slides.md) to see changes.

Notes:
- Custom minimal styles live in `styles.css` (loaded automatically by Slidev if referenced in theme or imported in slides).
- Reusable components in `components/`:
  - HmsHeaderBar, HmsTabs, HmsFlowButtons, HmsSimpleChart, HmsMockTable.
- Colors: primary #2563EB, secondary #64748B, accent #F59E42.
- This deck demonstrates Student Registration, Room Allocation, Complaint Management, Fee Tracking, and an Admin Dashboard mockup with interactive elements.
