# Hostel Management System — Slidev Presentation

This repository contains an interactive Slidev presentation that showcases:
- Student Registration
- Room Allocation
- Complaint Management
- Fee Tracking
- Admin Dashboard

Run locally:
- `cd slidev_frontend`
- `pnpm install`
- `pnpm dev`
- visit http://localhost:3030

Deployment:
- Netlify/Vercel configs are provided.
