# Hostel Management System — Slidev Presentation

This repository contains an interactive Slidev presentation that showcases:
- Student Registration
- Room Allocation
- Complaint Management
- Fee Tracking
- Admin Dashboard

Run locally:
- `cd slidev_frontend`
- `pnpm install`
- `pnpm dev`
- visit http://localhost:3030

Notes:
- You can override the port by setting the PORT environment variable, e.g. `PORT=3000 pnpm dev`. Ensure the port is free.

Deployment:
- Netlify/Vercel configs are provided.
